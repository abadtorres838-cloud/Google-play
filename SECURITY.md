# Security Policy

## Supported Versions

We provide security updates for the following versions of the project. Please ensure you are running a supported version to receive critical patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us in a responsible manner.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by sending an email to our security team at: **security@example.com**

Please include the following information in your report:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The version(s) of the software affected.
* Any possible mitigation strategies, if known.

You can expect an acknowledgment of your report within 48 hours. We will keep you updated on our progress towards a fix and will credit you in our security advisories if desired.
