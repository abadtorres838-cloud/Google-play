# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report security issues using GitHub's Private Vulnerability Reporting feature for this repository, or contact the repository maintainers directly. Do not report security vulnerabilities in public issues.
