# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities using GitHub's private vulnerability reporting feature on this repository.

Alternatively, you can reach out directly to the maintainers via secure channels. Do not use public issues to report security vulnerabilities.
