## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. To do this:
1. Go to the "Security" tab of this repository.
2. Click on "Advisories" on the left sidebar.
3. Click the "Report a vulnerability" button.

We will review your report and respond as quickly as possible.
