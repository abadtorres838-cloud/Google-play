# Security Policy

## Supported Versions

Please see the repository for currently supported versions.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the repository maintainer rather than creating a public issue.

We take all security vulnerabilities seriously and will work to address them in a timely manner. Please allow us a reasonable amount of time to respond and to fix the issue before publicizing it.

### What to include in your report

*   A description of the vulnerability.
*   Steps to reproduce the vulnerability.
*   Any potential impact.

Thank you for helping keep this project secure!
