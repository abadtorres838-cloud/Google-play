# Security Policy

Please check the following table to see which versions of the project are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities via email. We take all security issues seriously.

**Do not file a public issue.**

When reporting an issue, please provide the following:
* A description of the vulnerability.
* Steps to reproduce the vulnerability.
* Any known workarounds or mitigations.

We will try to acknowledge receipt of your vulnerability report within 48 hours and strive to provide a resolution or mitigation as soon as possible.
