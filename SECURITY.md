# Security Policy

## Supported Versions

We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainers rather than creating a public issue.

We will review the report and respond to you as soon as possible. Please include as much information as possible, such as:

- The type of vulnerability.
- The steps to reproduce the vulnerability.
- Any potential impact.
