# Security Policy

## Supported Versions

Currently, this repository is in early development. All active development happens on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please bring it to our attention right away!

Please **DO NOT** report security vulnerabilities through public GitHub issues.

Instead, please report them via email to the project maintainers. Include detailed steps on how to reproduce the issue so that we can verify and address it as quickly as possible.

We will endeavor to respond to your report within 48 hours and keep you informed of our progress towards a fix.
