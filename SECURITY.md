# Security Policy

## Supported Versions

We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT report it in the public issue tracker.

Instead, please report security issues through GitHub Security Advisories or contact the repository owner directly through private channels provided on the repository's main page.

All security vulnerabilities will be promptly addressed.
