# Security Policy

## Supported Versions

Currently, there are no supported versions of this project as it is an essentially empty repository.

## Reporting a Vulnerability

Please do not report vulnerabilities via email since there is no dedicated security email for this repository.

To report a vulnerability, please use [GitHub's private vulnerability reporting feature](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) if available, or contact the repository maintainers directly by opening an issue on GitHub.
