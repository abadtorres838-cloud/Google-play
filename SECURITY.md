# Security Policy

## Supported Versions

Currently, only the latest version of this project is actively supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's Security Advisories feature:

1. Go to the **Security** tab of this repository.
2. Click on **Advisories**.
3. Click on **Report a vulnerability** and provide details about the issue.

We will review your report and coordinate with you to resolve the vulnerability securely.
