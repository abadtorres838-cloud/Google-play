# Security Policy

## Supported Versions

Currently, the latest version of this project is supported with security updates.

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability in this project, please do not disclose it publicly.

Instead, please use GitHub's private vulnerability reporting feature to report any security vulnerabilities:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide details about the vulnerability, including how to reproduce it and the potential impact.

We will review your report and work with you to resolve the issue as quickly as possible.
