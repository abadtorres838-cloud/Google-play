# Security Policy

## Supported Versions

This project is currently in early development. While there are no actively supported versions for security updates yet, we take security seriously.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it via [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) feature on this repository.

If GitHub's Private Vulnerability Reporting is not available or suitable, please open an issue in the repository detailing the potential issue, and we will address it as soon as possible. Do not share sensitive details publicly.
