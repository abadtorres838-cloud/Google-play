# Security Policy

## Supported Versions

We are committed to resolving security issues in our project. Currently, the following versions are being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub Private Vulnerability Reporting**.

1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Provide a descriptive report including steps to reproduce the vulnerability.

We will review your report and respond as quickly as possible. We will work with you to understand and resolve the issue.

Thank you for keeping our community safe!
