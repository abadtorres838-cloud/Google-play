# Security Policy

## Supported Versions

Currently, the master branch of this repository is supported with security updates. If you are using a specific release, please upgrade to the latest stable release.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using GitHub's private vulnerability reporting feature (if enabled on this repository) or by privately contacting the repository maintainers through their GitHub profiles.

When reporting a vulnerability, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.

We will endeavor to respond to your report as quickly as possible and keep you informed of our progress towards a fix.
