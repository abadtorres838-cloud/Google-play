## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it
to the repository maintainers.

To report a vulnerability, please open a private security advisory on GitHub if
possible, or contact the maintainers directly through their GitHub profiles.

Please **do not** use placeholder email addresses or report vulnerabilities
publicly via regular issues until they have been resolved.

We will endeavor to respond to your report as quickly as possible and provide
updates on the status of the issue.
