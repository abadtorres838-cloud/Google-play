# Security Policy

## Supported Versions

Currently, the main branch of this project is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using GitHub Private Vulnerability Reporting:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide details about the vulnerability.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
