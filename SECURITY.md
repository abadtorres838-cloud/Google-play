# Security Policy

## Supported Versions

Please report security issues for this repository.

## Reporting a Vulnerability

We take the security of our software seriously. If you discover a security vulnerability in this project, please report it privately.

**Do not** open a public issue for security vulnerabilities. Instead, please use the private vulnerability reporting feature on GitHub by navigating to the "Security" tab of this repository, and clicking "Report a vulnerability" under "Advisories".

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
