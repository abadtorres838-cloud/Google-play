# Security Policy

## Supported Versions

Currently, only the latest version of the project is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them via [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability).

This allows us to receive the report privately and discuss the issue with you before it becomes public knowledge.
