# Security Policy

## Supported Versions

Please use the latest version for the best security and stability. If a vulnerability is found in an older version, we recommend upgrading to the latest release as we generally only provide security patches for the current major version.

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us securely.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via **GitHub Private Vulnerability Reporting**:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories**.
3. Click on **Report a vulnerability**.

Provide a descriptive summary of the issue, the steps to reproduce it, and any potential impact. We will review your report and respond as quickly as possible to discuss mitigation and next steps.

Thank you for helping keep this project safe!
