# Security Policy

## Supported Versions

Please check the project for active development branches. Security updates are typically applied only to the most recent version or main branch.

## Reporting a Vulnerability

We take the security of our project seriously.

To report a vulnerability, please do NOT create a public issue. Instead, please use GitHub's private vulnerability reporting feature for this repository by visiting the "Security" tab and clicking "Report a vulnerability".

This ensures that the vulnerability is kept confidential until a fix is available and deployed. We will review all reports and provide an update on the status.
