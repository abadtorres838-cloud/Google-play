# Security Policy

## Supported Versions

Please check the following table for the supported versions of this project.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them via GitHub's private vulnerability reporting feature for this repository, or by contacting the project maintainers directly via their public contact channels. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
