# Security Policy

## Supported Versions

Please see the repository for supported versions.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using GitHub's Private Vulnerability Reporting feature in this repository. Navigate to the "Security" tab of this repository, select "Advisories", and click "Report a vulnerability".

This ensures that vulnerabilities are disclosed responsibly and allows the maintainers to address them securely.
