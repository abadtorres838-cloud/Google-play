## 2024-10-27 - Security Policy Dummy Emails
**Vulnerability:** Use of generic or dummy email addresses (e.g., security@example.com) in `SECURITY.md`.
**Learning:** Placeholders in security documentation can misdirect sensitive vulnerability reports to unauthorized domains, potentially exposing 0-days or critical flaws to malicious actors.
**Prevention:** Avoid placeholder email addresses entirely. Use verifiable communication channels like GitHub issues (if appropriate for the threat model), direct messages on the platform, or authenticated keybases.
